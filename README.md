# Лабораторная работа №1: Работа со строками

Программа на C++, которая выполняет очистку текста от лишних символов в соответствии с вариантом задания.

## 📋 Задание
**Вариант (c):** Реализовать функцию удаления всех знаков препинания и служебных символов из строки.

## 🛠 Технологии
* **Язык:** C++ (стандарт C++17)
* **Компилятор:** g++ / Clang
