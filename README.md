# Проверка палиндрома на C++

Простая консольная программа на C++, которая проверяет, является ли введённая пользователем строка палиндромом.

## Описание

Программа считывает строку с пробелами, игнорирует знаки препинания, пробелы и регистр символов, а затем определяет, читается ли строка одинаково слева направо и справа налево.

Примеры палиндромов:
- А роза упала на лапу Азора
- Madam, I'm Adam
- 12321

## Требования

- Компилятор C++ (поддерживающий C++11 или новее)
- Стандартная библиотека C++
